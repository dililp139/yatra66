# 🇮🇳 Yatra - All-India Travel & Tourism Platform

Yatra is a full-featured, interactive Indian tourism web application built with **100% pure JavaScript, React 19, HTML5, and CSS3**.

Spring Boot and Java backend have been completely transitioned into an in-browser JavaScript engine (src/services/yatraService.js) with zero feature or data loss.

---

## ⚡ Quick Start

### 1. Install Dependencies
Run from the root directory:
`ash
npm --prefix frontend install
`

### 2. Start Development Server
`ash
npm start
# or
npm run dev
`
Open your browser at http://localhost:5173 (or network address displayed in terminal).

### 3. Production Build
`ash
npm run build
`

## 🚀 Key Features

1. **24 Indian Cities & Rich Profiles**
   - Jaipur, Agra, Delhi, Mumbai, Udaipur, Varanasi, Goa, Kochi, Amritsar, Manali, Rishikesh, Bengaluru, Hampi, Darjeeling, Shimla, Leh Ladakh, Mysore, Srinagar, Pondicherry, Hyderabad, Kolkata, Jodhpur, Ooty, and Shillong.
   - Comprehensive ratings, daily budget estimates, best seasons, high-res photography, and heritage descriptions.

2. **50+ Backpacker Hostels & Heritage Hotels**
   - Filter by budget, hostels (Zostel, Backpacker Panda, etc.), and luxury resorts.
   - 4-Platform live price comparison (Yatra Direct, MakeMyTrip, Agoda, Booking.com) with guaranteed lowest rate badges and coupon codes.

3. **Ola & Uber Live GPS Estimator**
   - Real-time GPS distance and road duration calculation.
   - Direct deep-links to launch native Ola and Uber booking interfaces with coordinates preloaded.

4. **Multi-Modal Transit Route Planner**
   - Intercity route options across Trains (Vande Bharat / Rajdhani), Flights, Volvo AC Sleeper Buses, and Highway Cabs.
   - Carbon footprint tracking and departure frequencies.

5. **AI Smart Trip Planner**
   - Customized day-by-day itineraries (Morning, Afternoon, Evening).
   - Budget breakdowns (accommodation, food, local transport, entry tickets).

6. **Live Satellite Weather & Wikipedia Insights**
   - Real-time live temperature, humidity, wind, and 7-day forecasts powered by Open-Meteo.
   - Encyclopedic facts and summaries powered by Wikimedia.

7. **Indian Festival & Holiday Calendar 2026**
   - Month-by-month guide to major cultural events (Diwali, Holi, Durga Puja, Pushkar Fair, Hornbill, etc.) with local celebration advice.

8. **Interactive Bookings & Reviews**
   - Instant reservation confirmation with unique YTR reference codes.
   - Full booking management (view, cancel) persisted in localStorage.
   - Community review system with star ratings and travel tips.

9. **Multi-Currency Support**
   - Live conversion rates across INR (₹), USD ($), EUR (€), GBP (£), AUD (A$), CAD (C$), SGD (S$), AED (د.إ), and JPY (¥).
